Create PostgreSQL table

Standard columns: column_name, data_type, data_size (type and length in separate columns, e.g. VARCHAR and 255). Each data row is one table column. You can still use a single data_type column with full types like VARCHAR(100) if you omit data_size. Enter connection details (host, port, user, password), Load databases to fill the database dropdown (or use the app default), choose the sheet and new table name, then create the table in the public schema. Passwords are not stored.

Allowed types match the import logic in utilities/excel_to_postgres.py. VARCHAR(n) and NUMERIC(p,s) must use valid numeric bounds.

PostgreSQL type (for your Excel) Typical use
BOOLEAN True/false
INTEGER 32-bit whole numbers
BIGINT Larger whole numbers
DOUBLE PRECISION Floating-point (IEEE double)
NUMERIC(p,s) Exact decimal; example NUMERIC(18,6)
DATE Calendar date
TIMESTAMP WITHOUT TIME ZONE Date and time (no TZ in column)
VARCHAR(n) Strings up to n characters
TEXT Unbounded text

Excel layout (standard): row 1 — column_name, data_type, data_size. Put the base type in data_type (e.g. VARCHAR, INTEGER) and the length or precision in data_size (e.g. 255). Optional scale for NUMERIC when precision is in data_size. Legacy aliases for the size column: size, length, max_length.
